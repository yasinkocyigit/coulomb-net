# Selected preliminary results

This folder contains three selected figures from development-stage
experiments:

- `model_comparison_preliminary.png` — comparison of regression approaches;
- `predictions_preliminary.png` — predicted versus reference charge values;
- `training_loss_preliminary.png` — training and validation loss history.

These figures are included to demonstrate the type of analysis performed in
the project. They are **preliminary**, may correspond to different experiment
configurations, and must not be interpreted as the final validated results of
the TÜBİTAK project. Exact metrics, configuration files, random seeds, data
generation settings, and trained model artifacts are intentionally withheld
from this public release.
